# Relance Mails

Outil de configuration et de suivi des relances par mail pour les chantiers paysage et espaces verts.

---

## À quoi ça sert

Gérer les relances chantier est chronophage et souvent oublié. Cet outil permet de :

- Configurer des séquences de relance par phase de chantier (EXE, OPR, AOR…)
- Personnaliser les mails par intervenant (entreprise, BET, architecte)
- Suivre l'état des relances en cours sur plusieurs projets simultanés
- Générer des mails pré-remplis avec les variables du projet

---

## Pour qui

Chargés de projets MOE · Conducteurs de travaux · Agences paysage · Bureaux d'études VRD
